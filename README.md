# Sakura 🌸

Sakura is a personal Japanese study website that organizes my class notes into searchable, easy-to-read tables.

The goal is to make vocabulary, grammar, and other topics quick to reference without searching through notebooks, PDFs or internet.

## Current Content

- Numbers
- Time

More topics will be added as I progress through my classes.

## Features

- Clean table-based layouts
- Fast search
- Simple static website
- Easy navigation between topics

## Built With

- HTML
- CSS
- JavaScript
